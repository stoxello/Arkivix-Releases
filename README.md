# Arkivix releases

This is the public binary distribution repository for Arkivix, a closed-source client/server backup system. The application source code is not published here and is not required to install or operate Arkivix.

- [Installation guide](https://stoxello.github.io/Arkivix-Releases/)
- [Latest release](https://github.com/stoxello/Arkivix-Releases/releases/latest)
- [All releases](https://github.com/stoxello/Arkivix-Releases/releases)

## Install the server with Docker

Docker Compose is the recommended installation method. It runs the published image, binds the administration interface to the local computer, and keeps Arkivix data in a persistent Docker volume.

Requirements: Docker Engine or Docker Desktop with Docker Compose.

### Windows PowerShell

```powershell
New-Item -ItemType Directory -Path arkivix -Force | Out-Null
Set-Location arkivix
Invoke-WebRequest `
  https://raw.githubusercontent.com/stoxello/Arkivix-Releases/main/docker-compose.yml `
  -OutFile docker-compose.yml
docker compose pull
docker compose up -d
```

### Linux or macOS

```bash
mkdir -p arkivix && cd arkivix
curl -fsSLO https://raw.githubusercontent.com/stoxello/Arkivix-Releases/main/docker-compose.yml
docker compose pull
docker compose up -d
```

Open [http://127.0.0.1:5198](http://127.0.0.1:5198). The `arkivix-data` volume contains server state and backup objects and remains intact when the container is replaced.

Upgrade to the latest image:

```bash
docker compose pull
docker compose up -d
```

View logs or stop the server:

```bash
docker compose logs -f
docker compose down
```

Do not run `docker compose down --volumes` unless you intentionally want to delete all Arkivix state and stored backups.

## Install a server binary

The [latest release](https://github.com/stoxello/Arkivix-Releases/releases/latest) contains self-contained x64 server archives that do not require the .NET SDK:

- `arkivix-server-win-x64.zip` for 64-bit Windows
- `arkivix-server-linux-x64.tar.gz` for 64-bit Linux

Extract the archive into a dedicated folder with write access, then run `Arkivix.exe` on Windows or `./Arkivix` on Linux. Runtime data is written to `App_Data` under that folder by default. Open `http://127.0.0.1:5198` after startup.

Use `SHA256SUMS.txt` from the same release to verify downloads before installation.

## Install an agent

Agents are installed from the Arkivix dashboard. Select **Add device**, generate a one-time enrollment code, then download the archive for the protected computer:

- `arkivix-agent-win-x64.zip` includes `install-agent.ps1`
- `arkivix-agent-linux-x64.tar.gz` includes `install-agent.sh`

Remote agents require an HTTPS server address. Follow the command generated by the dashboard so the server address, enrollment code, and protected path are correct.

## Network safety

The supplied Docker configuration publishes the administration interface only on `127.0.0.1`. Keep it loopback-only, or place an authenticated HTTPS reverse proxy in front of it before allowing network access. Back up the `arkivix-data` volume and maintain an off-site copy of important backups.
