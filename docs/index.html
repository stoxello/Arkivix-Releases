Install with Docker

Docker Compose is the recommended path. It keeps the dashboard local to the server, restarts automatically, and stores state in a named volume.

01 / DOWNLOAD

Get the public Compose file

No source checkout or build tools are required.

02 / START

Pull and run the image

Arkivix starts in the background and survives restarts.

03 / OPEN

Visit the dashboard

Open 127.0.0.1:5198 on the server.

mkdir -p arkivix && cd arkivix
curl -fsSLO https://raw.githubusercontent.com/stoxello/Arkivix-Releases/main/docker-compose.yml
docker compose pull
docker compose up -d
